# eTMF Backend Product Requirements Document (PRD)
*Note: This file is a read-only specification outlining discrete, actionable backend tasks.*

## Objective
Implement all remaining `Missing` and `Partial` features from the master project checklist to achieve full feature completeness for the eTMF Backend.

---

## 🏗️ Phase 4: Document Engine & Actions
- [ ] **Document Advanced Actions**: Copy, Move, Inactivate (Soft delete), Pin/Unpin, Link/Delink documents.
- [ ] **Document Collaboration**: Sticky notes / annotations, Access history per document, Version comparison (diff).
- [ ] **Document Processing**: Redaction, Blinding/Unblinding workflow, Convert/Upload PDF.
- [ ] **Upload/Download Utilities**: Quick upload (bypass wizard), Quick view (inline preview), Bulk download.

## 📂 Phase 5: Folder & Repository Management
- [ ] **Folder Structure Operations**: Implement Folder context menu logic, File plan setup.
- [ ] **Folder Constraints & Privileges**: Milestone due dates per folder, Assign/Revoke user group folder privileges, Folder lock.
- [ ] **Folder Reporting/Tracking**: Export folder contents, View folder history, Inventory doc count statistics, TMF Index generator.
- [ ] **Placeholder Management**: Set placeholders optional/mandatory, Remove placeholders.

## ⚙️ Phase 6: Study Setup, Workflow & Approvals
- [ ] **Study Setup Wizard**: Study creation wizard, Study templates & cloning, Document numbering engine (token builder).
- [ ] **TMF Lifecycle Management**: Study lock + pre-lock checklist, Archival/close-out workflow, TMF model migration utility.
- [ ] **Extended Workflows**: Absence management / auto-reassign, Signoff / publish step.

## 🔒 Phase 7: App Admin, Security & Integration
- [ ] **System Administration**: Metadata schema configurator, Document type master, Reason for signature templates.
- [ ] **Security**: IP allowlisting, Session timeout config.
- [ ] **AI & Integrations**: AI governance / bias monitoring module, Integrations screen (CTMS, EDC, RTSM, ePRO), Training / LMS integration.
- [ ] **Reporting Engine**: Blinded/Unblinded report, Timeliness report, Inventory report, Folder history report, Document move log, Notes & Schedule jobs report.
- [ ] **Multi-tenant Polish**: Tenant branding / white-label, Performance & scalability config.
